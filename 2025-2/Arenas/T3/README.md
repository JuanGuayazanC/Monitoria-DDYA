# Arena T3 (DDYA / AYED)

Enunciados de la Arena del tercer tercio. Basados en el libro *Competitive Programming 3* (con pistas de solución en varios casos) y en jueces en línea (UVa Online Judge); recurso adicional para depuración: [uDebug](https://www.udebug.com/).
